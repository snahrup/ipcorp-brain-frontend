# IP Corp Brain Explorer — Production Vision

**Owner Stance (as of 2026-05-28):**  
This is no longer a thin sanitized viewer. This is a premium, immersive interface whose job is to make the full `ipcorp-architecture-brain` feel alive, connected, and intellectually powerful.

The core experience must feel **distinct and sophisticated per major area**, with elegant 3D (and supporting 2D) knowledge graphs as the primary way users understand synthesis, provenance, and emergent insight.

## Core Principles

- **Premium but calm**: Dark, refined, layered, sophisticated. Motion explains state. No AI slop, no generic dashboard aesthetics.
- **Synthesis is the product**: The graphs must make it obvious that these insights and decisions are only possible because of how disparate data sources are captured, processed, and combined.
- **Distinct experiential textures**:
  - Meetings: Temporal, rhythmic, calendar/timeline + deep graph provenance.
  - Insights / Cortex: Spatial, relational, emergence-focused 3D graphs.
  - Project Memory / Decisions: Lineage, traceability, decision networks.
  - Systems & Architecture: Structural, dependency, control-surface views.
- **Steve-first + future multi-user**: Admin/preferential controls now (password-gated). Clear path to Entra ID + role-based experiences.
- **Real data, real connections**: We ingest from the actual brain repo. The graphs are not illustrative — they are the living model.

## Technology & Quality Bar

- 3d-force-graph (Three.js) as the primary visualization engine for knowledge graphs.
- Framer Motion + custom CSS for the surrounding experience.
- Clean, feature-based architecture (no more giant App.tsx).
- Performance-conscious (graphs can get heavy).
- Production hygiene: proper loading states, error boundaries, accessibility, theming system.

## Current Phase (May 28, 2026)

**Focus**: Establish the 3D Knowledge Graph as the unmistakable hero experience and prove the synthesis thesis with real brain data.

Next major milestones will be documented here as we progress.
