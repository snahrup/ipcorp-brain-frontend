# context/ — Layer 3 Training Materials

This folder contains the project's living standards, preferences, vocabulary, and examples of "good".

**Protocol (from global Steve rules):**
- Every file here must have exactly three sections: **Header**, **Content**, **Learnings**.
- Header tells you *when* to read it.
- Content holds the standards and examples.
- Learnings are dated one-liners appended when a correction or strong preference is discovered.
- When 3+ related learnings accumulate, graduate them into a new focused file.

## Current Files
- `design-system.md` — The canonical visual + interaction DNA (read before touching any CSS, motion, or layout).
- (Add more as the project matures: e.g. `data-contract.md`, `testing-standards.md`, `refactor-patterns.md`)

## How to Use
- On session start: skim the relevant files.
- After any correction from Steve (or a failed review): log the learning immediately as a dated bullet.
- Before large refactors or new features: re-read the applicable context file.

This is how the project teaches future agents (and humans) what "correct" looks like here.
