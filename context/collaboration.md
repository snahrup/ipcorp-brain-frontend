# Delegated Task Coordination

## Header

Read this before working on a request assigned from another task.

## Content

The originating task owns material product decisions. Continue independently only inside the approved scope, report concrete findings promptly, and pause when a choice would materially change the solution.

## Learnings

- [2026-08-04] For delegated work, do not choose material product direction independently. Send the finding or question to the originating task and wait for direction.
- [2026-08-06] When Steve requests a full feature spec, write it as a self-contained instructional prompt that can be pasted directly into another coding task without extra context.
